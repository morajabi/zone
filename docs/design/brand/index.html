Four compact directions for a menu-bar focus app. The artwork uses no external assets or fonts. Each is shown at 128 px and at 16, 24, and 32 px below. Switch the system appearance to inspect both palettes.

Recommended direction

Quiet orbit

One ring, one point, one muted accent. The open ring belongs to the app's existing identity, while the warmer green and near-white stroke improve its contrast. Keep it still: the app's timer supplies progress, so the mark does not need to animate.
