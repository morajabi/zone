# Native pattern explorations

Eight standalone, dependency-free interactive HTML spikes. Each supports starting, pausing, resuming, and ending a flexible session, plus block-list editing, schedule creation, locked mode, and pause options. Light and dark appearance follow the system. Timers are simulated; these files never block websites or launch apps.

Recommended combination: **04 Menu Bar Essential** for the menu-bar panel and **01 Clock Face** for the main focus window. Borrow **06 One Outline** for compact disclosure of infrequent configuration.

The simplification is structural: keep duration and Start prominent; replace always-visible presets, list editing, mode toggles, pause steppers, and multiple footers with two summary rows. During a session, preserve one primary Pause/Resume action and a quiet End action only in flexible mode. Locked mode requires confirmation and omits End.

Pattern source: Apple native app pattern atlas, macOS 27.0 (26A5416b), August 22, 2026: Notes split view and compact preferences; Calendar toolbar roles; HIG guidance for scoped sheets, sidebars, and toolbar groups. Clock and Reminders names describe design interpretations, not screenshot-backed framework claims.

See `metadata.json` for the full ranking, tradeoffs, and idle control counts.
